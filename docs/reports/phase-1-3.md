## Problems found

- Posters redirect from yts.gg to img.yts.gg, and the original code didn't follow any redirects, so it couldn't get them; fixed (only follows the same domain or subdomains, rechecking at every hop).
- The fake YTS has no posters, so the browser console in the dev environment shows a row of 404s (one per card). This doesn't affect the page (placeholder posters are drawn).
- `STORAGE_LIMIT_GB` in `deploy/.env` defaults to 50, so your storage limit is currently 50 GB. Change it in "Storage management" according to your disk size and what you want.
